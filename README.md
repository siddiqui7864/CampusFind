# 🔍 Findora

A campus lost & found web portal — report, browse, and claim lost items with filters, search, and an admin dashboard. Built with vanilla HTML, CSS & JS.

---

## 📖 About

**Findora** is a fully client-side lost and found portal for college campuses.  

Students can:
- Report lost or found items  
- Browse listings with filters (category, location, status, date)  
- Search for specific items  
- Contact reporters directly  

---

## 🛠️ Admin Dashboard

A password-protected admin panel allows staff to:
- Manage all submissions  
- Update item status (lost/found/resolved)  
- Remove resolved or invalid entries  

---

## ⚡ Tech Stack

- HTML  
- CSS  
- JavaScript  
- localStorage (for data persistence)  

---

## 🚀 Features

- 🔍 Smart search functionality  
- 🗂️ Filter by category, location, and date  
- 📌 Status tracking (Lost / Found / Claimed)  
- 🔐 Admin control panel  
- 💻 Fully client-side (no backend required)
